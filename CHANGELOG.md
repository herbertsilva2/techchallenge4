# Changelog

Todas as mudanças notáveis para este projeto serão documentadas neste arquivo.
O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/).

## [1.0.0] - 2026-07-17
### Adicionado
- Versão final do Tech Challenge Fase 4 preparada para portfólio.
- Interface gráfica (Dashboard Streamlit) com design Apple Premium.
- Automação via GitHub Actions para CI/CD (Testes via pytest).
- Geração de artefatos multimodais e relatórios completos.
- Inclusão de documentação de alto nível (Mermaid, diagramas, shields).

## [0.5.0] - 2026-07-15
### Adicionado
- Integração do Azure AI Speech para transcrição em `pt-BR`.
- Integração de modelos MediaPipe (Face Detection).
- Arquitetura de microserviços e pipeline assíncrono.
- Componente de detecção de objetos com YOLOv8n.

## [0.1.0] - 2026-07-10
### Adicionado
- Inicialização do repositório.
- Prova de conceito (PoC) local.
- Separação de frames via OpenCV.
